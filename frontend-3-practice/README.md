# Контур · Выбор даты и времени на React

В папке `frontend-3-practice` выполните:

```sh
npm install
npm run dev
```

Откройте адрес, который напишет Vite. Для этого шаблона подходят Node.js 22.13+ или 24.

Календарь, слоты и нижняя панель вынесены в компоненты. Данные и функции для дат находятся в `src/data/date.js`, состояние записи — в `src/App.jsx`. Стили и демонстрационные данные перенесены из второй практики.

- Пока 4 декабря 2026 года доступно, эта дата выбрана по умолчанию. Позднее выбирается ближайший день со слотами.
- Выберите 14:30 на 4 декабря. Время появится в нижней панели и активирует «Далее».
- Выберите 5 декабря. Время сбросится, а в расписании появится сообщение, что доступных слотов нет.
- Перелистайте месяцы стрелками. Прошедшие дни приглушены и недоступны для выбора.
- «Далее» открывает демонстрационное окно с выбранной датой и временем.
