# Контур · React-календарь с имитационным API

В папке `frontend-4-practice` выполните:

```sh
npm install
npm run dev
```

Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd install` и `npm.cmd run dev`. Откройте адрес из строки **Local** и оставьте терминал открытым.

Для работы API нужен режим `npm run dev`: имитационный сервер подключается как плагин Vite.

## Проверка

1. При запуске появится «Загрузка…», затем календарь на декабрь 2026 года. Серверная «сегодняшняя» дата — 4 декабря.
2. После «Загрузка слотов…» выберите 14:30. Время появится в нижней панели, а «Далее» откроет демонстрационное окно.
3. Нажмите 5 декабря. Выбор времени сбросится, а после загрузки появится сообщение, что свободных слотов нет. В демонстрационной базе чётные даты используют один набор слотов, нечётные показывают пустое расписание.
4. Проверьте стрелки. Дни раньше 4 декабря приглушены и недоступны.
5. Чтобы проверить ошибки в браузере, временно заблокируйте запрос `*/api/slots*` в DevTools и выберите другой день. Для проверки ошибки начальной загрузки заблокируйте `*/api/booking/today*` и обновите страницу.

`GET /api/booking/today` отдаёт дату из `server/database.js`. `GET /api/slots?day=4&month=11&year=2026` отдаёт слоты. Месяцы нумеруются с нуля.
